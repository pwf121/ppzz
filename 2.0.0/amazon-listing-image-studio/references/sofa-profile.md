# 沙发产品认知

按实际配置适配固定、模块、贵妃位、L/U形、沙发床、手动/电动躺靠等，不由名称自动添加储物、拆洗或电动功能。

| 维度 | 确认内容 |
|---|---|
| 整体与模块 | 座位/模块数量、连接、左右扶手、靠背轮廓、底座/脚，每种组合独立配置ID |
| 方向 | 贵妃位以“面对产品”或“坐在产品上”的明确视角约定，未知先问，不镜像猜测 |
| 软包 | 坐垫/靠垫数量、厚度、饱满度、分缝、滚边、纽扣、面料张力 |
| 材质 | 声明的织物/皮革成分与可见表面分开；织纹尺度、绒向、光泽、颜色按本品参考 |
| 功能 | 固定/手动/电动、展开与躺靠范围、储物位置、模块移动、可拆洗范围 |
| 配件尺度 | 标配靠枕/脚凳/电源数量，尺寸单位/测量状态；道具不冒充标配 |

方向未明确不输出确定左右。展开图需对应实物状态/规格，不由闭合外观臆造机构。外观不能证明真皮、防污、耐磨、宠物友好或可拆洗；性能/人体工学宣称需证据。

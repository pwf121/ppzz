# 可选变体套版

只在用户要求且首套已由用户确认定稿后启动。不是所有项目的必选项；没有要求就不询问颜色、不新增变体图位、不额外消耗生成。

## 门槛与流程

1. 锁定母版所选图片、排版、产品事实版本、需求与导出清单及哈希；保存用户定稿确认的来源。文件校验PASS不能代替用户确认。
2. 获取目标变体的真实照片/材质说明/色样，逐项比较结构、尺寸、功能、配件。仅颜色或材质可套版；其他事实变化退回产品学习，明确受影响图位。
3. 保持产品结构、比例、部件数量、相机、构图、场景、人物、动作、道具、文案布局和字体。仅替换颜色/材质。材质更换不能擅自添加实木、真皮、耐抓、防污等卖点。
4. 检查原文案的颜色/材质/性能描述是否仍适用；冲突先集中确认，获准后才改相关文字，不能静默保留错误宣称。
5. 每个变体先做1张风险代表样图；核对产品与非产品元素，样图确认后套用其余正式图位。AI不能保证像素级锁定；出现非目标漂移就拒收，按重复错误止损规则补参考/换获准路线。
6. 默认使用同一项目内独立变体批次、各自双版本目录。保留母版和各变体原生文件，不覆盖原图、不用母版旧QA证明变体通过。

## 兼容记录

不新增operation枚举；套版是已授权new批次或revise操作中的可选分支。没有变体数据的旧项目保持原行为。

导出清单可选`variant_template`：`variant_id`、`master_manifest_path`（绝对路径）、`master_manifest_sha256`、`master_approval`（user_confirmed）、`changed_attributes`（仅color/material）、`reference_paths`（非空真实资料绝对路径）、`sample_visual_qa`（PASS）、`copy_review`（PASS）、`approval_source`（用户确认的可追溯说明）。母版清单与变体export_root必须不同且互不嵌套，默认使用并列批次。

校验器只核验文件关联、范围声明、审核声明和母版不被目标路径覆盖，不证明颜色正确、照片符合材质或用户确实批准。真实确认、逐图视觉QA和reviewed_sha256仍必需。master_approval缺失、样图未过、文案待确认或变化超出范围时禁止交付为完成。

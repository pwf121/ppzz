# 柜类产品认知

只检查当前实际部件，覆盖书柜、电视柜、餐边/储物柜、鞋柜、斗柜、床头柜、衣柜、浴室/厨房柜及组合柜等；品类名不证明具体配置。

| 维度 | 确认内容 |
|---|---|
| 轮廓与安装 | 宽深高来源/单位、顶板厚度、突出边、底座/脚、落地/壁挂/嵌入关系 |
| 分区与开合 | 门/抽屉/开放格数量、隔板连接、左右门与开合方向、固定/可调部件 |
| 五金 | 把手、铰链、滑轨、磁吸、门挡、包角是否存在，数量、位置与相对尺度 |
| 材质 | 基材/面层分别记录，纹理方向、颜色、反射、玻璃/镜面与可见边缘 |
| 功能 | 调节适用部件/档位、抽屉行程、储物/安装；灯、电源、升降仅确认后加入 |
| 附件与限制 | 标配/选配、安装附件；“不突出宣传”不等于可以删除实物部件 |

图中相对位置不等于精确毫米尺寸，角度不同不能机械复制像素坐标。开门/闭门需匹配同一产品，隐藏五金不能套常见配置。新确认与旧渲染冲突时列受影响图，确认事实后更新。

样图从正式图位选择整体、本轮内部/开合或高风险五金；无门不要求开门，未确认可调不画调节功能。实木、防水、防倾倒效果、承重、安全/电气认证需合格资料，不由外观推断。关键未知仅阻断相关图。

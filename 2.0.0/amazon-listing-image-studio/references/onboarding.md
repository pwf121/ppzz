# 开场指南

适用：本Skill已被选中、明确调用，或任务已明确属于Amazon套图流程。任意消息入口仅适用于前两种，不把无上下文的数字/符号加入泛化触发词。

## 执行顺序

1. 先识别明确意图：停止/取消立即尊重；询问能力、升级Skill等只回答相应问题，不自动启动制作。
2. 识别当前任务是否已有流程记录。续做只报告进度、缺口及下一步，不重复开场；新任务进入以下引导，不追踪跨任务用户身份。
3. 提取已知资料，不要求重填。没有资料时主动说明四点：需要用户提供什么、放在哪里、助手做什么、交付什么及确认节点。
4. 部分资料只集中询问影响下一阶段的最小缺口。资料齐全时简短说明“先核实产品，再完善图需并校样”，继续已授权工作，不要求用户再发启动口令。
5. 问候/数字/符号不是写入或调用生图授权。资料收齐不等于已获无限授权；按主流程生成门执行。

## 推荐引导内容（根据已有信息删减）

我会先了解产品结构、材质和真实功能，再结合图需与竞品参考完善方案，确认代表样图后制作整套，最后分别交付无文案版和有文案版。

请先提供产品图片或文件夹路径；已有图需表、竞品链接、尺寸和材质说明也可以一并发送。再告诉我Amazon站点、想做的主图/副图/A+范围，以及成品保存位置。不必一次填完，我会只提示当前缺少的关键资料。

原始图片保留在用户提供的位置，不要求搬迁；成品放用户指定或确认的目录。尚未给保存位置时先提出目录建议，不静默创建。数量/尺寸未知时明确待定，不预设9张、2000像素或某个示例产品。

确认节点：事实冲突、图需重要变动和代表样图。已明确的信息不重复批准；新增授权之外的研究、生成、上传不自动执行。

## 正反例

- 已选中Skill＋“1”：简短引导并询问产品资料；不报错、不搜Top10、不创建文件。
- 已选中Skill＋完整图需：确认收到、说明下一步，只问真实缺口。
- 已选中Skill＋“取消”：停止，不继续引导。
- 既有项目＋“继续”：先核对项目状态，只处理缺失或失效图。
- 未选中＋“？”：不假定用户要做Amazon图片。

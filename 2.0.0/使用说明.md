# 家居电商图片工作室 2.0

Skill：amazon-listing-image-studio
版本：2.0.0

用于Amazon主图、副图和A+，重点适配柜类与沙发。先核实结构、材质与功能，再完善图需、研究竞品、确认校样，最后分别交付有文案、无文案和可编辑文字层。

## 安装与启动

1. 解压后，将完整的 `amazon-listing-image-studio` 文件夹放入当前用户的 Codex Skills 目录。Windows常用位置为 `%USERPROFILE%\.codex\skills`，不要多套一层目录；最终应能找到 `amazon-listing-image-studio\SKILL.md`。
2. 已有同名版本时先备份，不直接合并覆盖；留意项目内同名Skill可能与全局版本并存。
3. 新建任务，明确发送：`请使用 $amazon-listing-image-studio，开始引导，暂不生成图片。`

选中本Skill后，“你好”“1”“？”也可启动引导；未选中时普通消息不应被拦截。提供站点、产品图片/素材路径、结构尺寸材质、需求表或参考链接、图片范围与输出路径即可逐步开始。

## 升级要点

- 先学习产品事实，按柜类/沙发分别核查，减少结构错误返工。
- 默认轻量竞品研究；明确要求时保留Top10；纯分析不强制本品图需表。
- 先校样后批量；同类结构/关键材质连续两次错误暂停补证。
- 多场景先独立生成并验收，再拼版；单张素材保存到无文案目录，不重复计正式图位。
- 默认字体按角色统一；用户明确授权的局部例外需单独记录与QA。
- 首套用户定稿后可选颜色/材质套版，独立保存、不覆盖母版；结构变化重新核实。
